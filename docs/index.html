GDrive Bridge

GDrive Bridge is a personal add-on for the Kodi media player. It lets Kodi on your own device browse and play the videos in your Google Drive, as if Drive were a network share.

  • It asks Google only for read-only access to your Drive.
  • It runs entirely on your own Kodi device. Your files stream straight from Google to that device and are not sent anywhere else.
  • It never changes, uploads or deletes anything in your Drive.

You can remove its access at any time in your Google Account under Third-party apps & services, or by choosing Sign out in the add-on.

Get it

Install the GDrive Bridge repository once; Kodi then keeps the add-on up to date. In Kodi:

  1. Settings > System > Add-ons: turn on Unknown sources.
  2. Settings > File manager > Add source: enter https://gdrive-bridge.github.io/gdrive-bridge/repo/ and name it GDrive Bridge.
  3. Settings > Add-ons > Install from zip file > GDrive Bridge: choose repository.gdrivebridge-1.0.0.zip.
  4. Install from repository > GDrive Bridge Repository: install GDrive Bridge.

Then open the add-on and choose Set up on phone or computer; the setup page walks you through the rest. (Each release is also on Releases, but a copy installed from that zip doesn't update itself.)

Source code and documentation: https://github.com/GDrive-Bridge/gdrive-bridge
